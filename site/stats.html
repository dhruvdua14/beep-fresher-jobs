Daily runs

How it works

  1. FetchEvery morning at 8:00 IST a GitHub Action calls the public job-board APIs that Greenhouse, Lever, Ashby, SmartRecruiters, Workable and Recruitee publish for companies' careers pages. These are meant to be read by other sites, so nothing is scraped and no site's terms are broken.
  2. FilterRegex rules keep posts located in India and drop titles like Senior, Lead or Manager. A post stays if its title says intern, trainee, graduate or junior, or its description says 0–1 years or freshers.
  3. Remove duplicatesAn exact pass hashes company, title and location. A fuzzy pass compares titles from the same company with rapidfuzz, treating “Bangalore” and “Bengaluru” as one place, and drops anything 92% similar.
  4. TagGemini reads 20 posts per request and must answer in a fixed JSON schema: one role from 15 categories, cities from a fixed list, a level, and a confidence score. It also acts as a second filter by rejecting posts that need experience. Posts tagged on an earlier day are cached and never paid for twice.
  5. PublishThe run writes a JSON file into the repo and redeploys this static site on GitHub Pages. Search and filters run in your browser, so there is no server to keep alive.
